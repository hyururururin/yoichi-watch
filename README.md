# 余市蒸溜所 空き枠ウォッチャー

ニッカ余市蒸溜所のガイドツアー予約ページを定期的に見に行き、指定日に空きが出たらスマホへ通知します。

対象日の既定値: **2026-10-17 のみ**（10/18以降は解禁日の朝9:15に手動で取る想定）

---

## 0. 先に知っておくこと（重要）

- 予約受付は **先4週間分のローリング方式**。毎朝 **9:15頃** に1日分ずつ新しい日が解禁されます。
- 10/17 は **9/19 の 9:15 に解禁済み**。つまりこの日はもう新規解禁が来ないので、
  残るのは **キャンセル拾いのみ**。このツールの役割はここです。
- 10/18 は 9/20、10/19 は 9/21 の各 9:15 に解禁。こちらは手動で取るのが確実です。
- WEB予約は前日まで可能なので、10/17枠は **10/16 まで**拾えるチャンスがあります。
- キャンセル待ちの仕組みは公式には無く、キャンセル空きはリアルタイムで反映されます。
- 公式は「予約とキャンセルの繰り返し」を制限対象としています。**自動予約はしない**こと。
  この仕組みは通知までにとどめ、予約は人が手で行う設計にしています。

---

## 1. 通知先を決める（ntfy が一番かんたん）

1. スマホに **ntfy** アプリを入れる（iOS / Android、無料）
2. アプリで適当なトピック名を購読する。例: `yoichi-naoki-8f3k2`
   （トピック名は誰でも購読できるので、推測されにくい文字列にする）
3. そのトピック名を `NTFY_TOPIC` に設定する

Discord を使う場合は、サーバー設定から Webhook URL を作って `DISCORD_WEBHOOK` に入れてください。

---

## 2. まずローカルで調査モードを1回流す

```bash
pip install -r requirements.txt
python -m playwright install chromium

python check_yoichi.py --dump
```

`debug/` に以下が保存されます。

- `page-*.html` … レンダリング後のHTML
- `text-*.txt` … 画面の表示テキスト
- `api-*.json` … 予約サイトが内部で叩いているAPIの応答

**このうち `api-*.json` の中身を確認して、空き状況がどのキー名で入っているかを特定します。**
（判定ロジックは `judge_from_api()` の `nums` 正規表現と `OPEN_WORDS` で調整できます）

`--dump` の最後に各対象日の仮判定が出るので、それが実際のサイト表示と一致していればそのまま使えます。

---

## 3. 常時監視の動かし方

### 方式A: GitHub Actions（PCを閉じていても動く。おすすめ）

1. プライベートリポジトリを作り、このフォルダ一式を push
2. Settings → Secrets and variables → Actions で
   `NTFY_TOPIC`（必要なら `DISCORD_WEBHOOK`）を登録
3. Actions タブから `yoichi-watch` を一度手動実行して動作確認

既定は終日10分おき。キャンセルは夜間にも出るため時間帯は絞っていません。GitHub の無料枠は月2,000分なので、1回2分として十分収まります。
※ スケジュール実行は数分遅れることがあります。秒単位の勝負には向きません。

### 方式B: 自宅PC（Windows タスクスケジューラ）

PCが起動している間だけでよければこちらが最速です。

```
プログラム: python
引数:      C:\path\to\check_yoichi.py
開始:      C:\path\to\yoichi-watch
トリガー:  毎日 9:00 開始 / 5分ごとに繰り返し / 継続時間 9時間
```

環境変数 `NTFY_TOPIC` はユーザー環境変数に登録しておきます。

---

## 4. 頻度について

5〜10分間隔にしてください。相手は一般の企業サイトで、公開APIではありません。
1分未満の高頻度アクセスは迷惑になるうえ、遮断される可能性もあります。

---

## 5. ツアー種別で絞る

種別を問わず通知したいなら `TOUR_KEYWORD` は空のままでOK。
「通常のガイドツアーだけ」「テイスティング付きだけ」に絞りたい場合は、
`--dump` で取れた `api-*.json` に出てくる実際の名称をそのまま入れてください。

```
TOUR_KEYWORD="ガイドツアー"
```

---

```

debug/                     --dump の出力（自動生成）
```
